# 🐰 Bailey Bunny on Acme Street!

**An original endless runner starring Bailey Bunny — free to play, share, preserve, and enjoy!**

Welcome to Acme Street, where bombs litter the roads, gold coins are lying around, and common sense seems to have taken a vacation!

After eating a lot of brownies and pizza, Bailey Bunny decides to go jogging around town. Unfortunately, he discovers Acme Street, a place where dodging explosive obstacles and collecting abandoned money are just part of the daily routine.

Can you help Bailey survive?

## 🎮 About the Game

*Bailey Bunny on Acme Street!* is a lightweight, browser-based endless runner built with HTML, CSS, and JavaScript.

### Features

- 🐰 An original adventure starring Bailey Bunny
- 💣 Dodge bombs and other obstacles
- 🪙 Collect gold coins as you run
- 🏆 Keep track of your score
- ⚡ Arcade-style endless running
- 📱 Simple, accessible controls
- 📺 Direct access to Goofbox, a 24/7 classic-cartoon streaming experience

## 🕹️ How to Play

1. Open `index.html` in a compatible web browser, or visit the hosted version when available.
2. Press **Start Game**.
3. Use the left and right arrow buttons to switch lanes.
4. Avoid bombs and other obstacles.
5. Collect as many gold coins as possible.
6. See how long you can survive!

## 📺 Goofbox — Classic Cartoons 24/7

Want a cartoon break between runs?
